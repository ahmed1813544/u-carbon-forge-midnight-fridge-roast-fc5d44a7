A one-line roast of a smart fridge that refuses to open after midnight, written by a small Python program for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun.

## How it works

`main.py` (stdlib only, deterministic) writes a single roast line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> My smart fridge locks at midnight, so my leftovers have a curfew and I'm grounded from my own sandwich.

## Run it

```sh
python3 main.py
```
